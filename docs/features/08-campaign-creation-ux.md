# Campaign Creation UX

## Goal
Create a campaign with the fewest possible decisions.

## Primary flow
1. Name
2. Creative assets
3. Platforms
4. Budget
5. Dates
6. Destination
7. Create

## Proposed screen
Campaign name  
[ Raw UGC / Summer Push ]

Creative assets  
[ Video A ] [ Image + Text B ] [ + Add ]

Platforms  
[ Meta ] [ Google ] [ TikTok ]

Budget  
[ $2,500 ]

Run  
[ Start date ] → [ End date ]

Destination  
[ https://business.com/offer ]

[ Save Draft ] [ Create Campaign ]

## Platform connection
If selected platform is not connected:
Meta — Not connected — [ Connect Meta ]

Complete authorization, then return to the same campaign creation state.

## Defaults
- autosave unfinished draft
- no advanced platform-specific settings initially
- no targeting strategy, automation, or analytics configuration here

## Principle
The creation experience should feel like setting up a media run, not configuring ad-tech infrastructure.
