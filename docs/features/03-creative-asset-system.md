# Creative & Asset System

## Asset types
- Image
- Text
- Image + Text composition
- Video
- Audio

## Asset vs. Creative
An **asset** is reusable source material. A **creative** is an advertisement assembled from one or more assets.

Example:

Assets:
- product-photo.jpg
- headline text
- logo.svg

Creative:
- image + headline + logo + CTA

## Asset library
Assets belong to the business, not to a single campaign. A single asset may be reused in multiple creatives and campaigns.

## Creative versioning
Creative history must be immutable for measurement purposes. Meaningful changes create a new creative version or deployment rather than overwriting historical creative.

## Hosted creative
Every creative may receive a public/shareable hosted URL by default.

Example:
`https://ads.example.com/c/abc123`

Useful for email, SMS, QR codes, websites, social links, and image+text compositions that need a stable rendered form.

## Minimum performance history
- impressions/views
- clicks
- leads
- sales
- spend
- revenue

## Principle
Creative should exist independently from the platform on which it is deployed.
