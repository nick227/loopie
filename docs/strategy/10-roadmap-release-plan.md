# Roadmap & Release Plan

## Goal
Reach a pilot-ready messaging and customer-relations POC with the smallest coherent feature set.

## Milestone 1 — Core Data
Build accounts, contacts, contact import, channel eligibility, basic customer/lead status, and interaction history.

**Success:** Contacts can be imported, searched, deduped, and viewed reliably.

## Milestone 2 — Messages
Build audience selection, email composer, text composer, social-post draft support, send/test/schedule, and delivery status.

**Success:** A pilot user can send a real message to a selected audience.

## Milestone 3 — Templates
Build default templates, save as template, reuse past message, and personalization.

**Success:** Common outreach can launch without rewriting content.

## Milestone 4 — Follow-Up
Build one/two-step automatic follow-up, reply detection, stop conditions, reminders, and automation logs.

**Success:** A message can safely trigger a follow-up without manual intervention.

## Milestone 5 — Customer Context
Build contact side panel, communication timeline, notes, lead status, and sale outcome.

**Success:** A user can understand the relationship without leaving Messages.

## Milestone 6 — Results
Build sent/delivered/opened/clicked/replied, leads, sales, recorded revenue, and basic per-message reporting.

**Success:** A user can answer, “What happened after we sent this?”

## Milestone 7 — Pilot
Run with 2–3 businesses.

Observe what users misunderstand, which fields are ignored, where human assistance is required, which automations are repeatedly requested, and where sending or tracking fails.

## Release Rule
Do not add Phase 2 concepts until pilots demonstrate need.

Likely Phase 2: review outreach, richer automation, deeper sales tools, ad attribution, prospect discovery, multi-account management, white labeling, and AI-assisted content.

## POC Definition of Done
A business can import customers, choose an audience, send a message, automatically follow up, receive replies, mark a sale, and understand the outcome from one coherent product experience.
