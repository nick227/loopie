# UX / Information Architecture

## Top-level navigation
- Dashboard
- Campaigns
- Assets
- Contacts

## Dashboard
Top-line:
- Spend
- Leads
- CPL
- Active campaigns

Then active campaigns and optional Top Creative / Top Platform callouts.

## Campaigns
List:
- name
- status
- platforms
- budget/spend
- dates
- compact funnel/performance

## Campaign workspace
Primary surface for:
- creatives
- platforms
- budget
- dates
- deployment status
- performance
- pause/resume
- extend
- duplicate
- end

## Assets
One library with type filters:
- images
- text
- image + text
- video
- audio

## Contacts
Minimal CRM:
- leads
- customers
- source
- sale/revenue

## Contextual surfaces
Do not create top-level navigation for integrations, platform auth, add asset, edit creative, duplicate campaign, extend campaign, or account settings.

## Principle
Almost every advanced action should be reached through a campaign rather than becoming another section of the application.
